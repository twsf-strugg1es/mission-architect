2. GAME
   Run the game: npm ci, then npm run dev. Build: npm run build (output: dist/).
   Netlify deploy: build command `npm run build`, publish directory `dist`.

3. VIDEO EDIT
   Re-run the video edit: see tools/video/build_video.py — it needs the
   align-*.json files and the Geist fonts named here.
   - Usage: python3 build_video.py a   (Video A)   |   python3 build_video.py b   (Video B)
   - Needs: ffmpeg (with libass), Python 3 with numpy and Pillow.
   - Word timings: tools/video/align-a.json and tools/video/align-b.json
     (script text forced-aligned to the voiceovers with CMU PocketSphinx).
   - Fonts used (NOT included in this zip): geist-latin-wght-normal.ttf and
     geist-mono-latin-wght-normal.ttf. These are TTF conversions of
     tools/video/remotion/public/fonts/geist-latin-wght-normal.woff2 and
     geist-mono-latin-wght-normal.woff2 (converted with fontTools).
     The subtitle renderer looks for them in a fonts folder.
   - The script still contains the paths of the machine it was made on
     (/home/claude/...). Edit the path lines at the top of the script
     (ROOT, W, the align-*.json path, the font paths and the fontsdir)
     before running it on your PC.
